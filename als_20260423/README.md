# als_20260423 — crystal size series (3 datasets)

This directory contains X-ray Bragg and diffuse scattering datasets from three Mac1 crystals generated as part of Prism, Astera Institute's effort to develop reproducible methods for generating high quality, diffuse scattering data. These datasets resulted from experimenting with protein crystallization conditions and are considered poor quality due to low SNR.

Beamline: 8.3.1, ALS (Advanced Light Source), Berkeley, CA — April 23, 2026

| dataset | logbook entry |
| --- | --- |
| mac1_4 | [link](https://diffuse.science/logbook/beamtime/20260423_als/#mac1-apo-4) |
| mac1_6 | [link](https://diffuse.science/logbook/beamtime/20260423_als/#mac1-apo-6) |
| mac1_7 | [link](https://diffuse.science/logbook/beamtime/20260423_als/#mac1-apo-7) |

Each `mac1_N/crystal/` folder contains the raw Bragg + diffuse frames for that crystal; `mac1_N/background/` contains the matching background images.
